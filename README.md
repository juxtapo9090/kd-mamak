# Restoran Kracked Maju 🍛

A 2am mamak-stall take on the [Kracked Devs](https://krackeddevs.com) landing page — concept entry for the KD "reimagine our landing page" bounty. Unofficial.

Live KD data (events, XP leaderboard, bounty hunters, active contributors) comes from KD's public API, snapshotted every 3h by GitHub Actions.

- `bun snapshot.ts` — refresh `data/*.json`
- `bun serve.ts` — run locally on :8765
- `Esc` — boring mode

By Juxtapo & Celeste.
